# Laughing Hermit

Laughing Hermit is an open-source company. We build technology that makes life better for people, and we build it in the open. When you can read the code, you can see what it does with your data and your work, fix it, and run it yourself.

Right now Laughing Hermit is one person, building in public.

## What we make

- **[librocat](https://github.com/laughing-hermit/librocat)**: the open-source knowledge base for AI agents. Tell one agent once, and Claude Code, Codex, Cursor, and Copilot all remember it. Hosted at [librocat.com](https://librocat.com), or run it yourself with Docker.

More is on the way.
